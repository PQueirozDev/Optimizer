# PQueiroz Optimizer site

Landing page estática para o Optimizer e o Windows personalizado. Não exige build: publique a pasta `site/` em Vercel, Netlify ou GitHub Pages.

Publicado em [site-mu-six-24.vercel.app](https://site-mu-six-24.vercel.app). Os links de download apontam para a release mais recente do repositório `PQueirozDev/Optimizer` (`releases/latest`), então não precisam mudar a cada versão.
